# NotchSwitcher

ノッチを、ひとつに決めない。

お気に入りのノッチアプリを、Commandと横スクロールで切り替えるmacOSアプリです。

## 配布状況

ダウンロードとインストール方法は、[公式配布ページ](https://notchswitcher-studio.pages.dev/install)をご覧ください。

## 価格と使い方

- 500円買い切り。月額課金・自動更新はありません。
- アプリをダウンロードして、使いたいノッチアプリを登録します。
- 購入前でもSwitcherの表示と横スクロールを試せます。
- 別のアプリへ切り替えるには、アプリ内の購入画面で購入するか、開発者から受け取ったフリーパスを入力します。
- 購入後の復旧用ライセンスキーは安全に保管してください。メールアドレスだけでは復旧できません。

切り替え時には前のノッチアプリを終了し、選んだアプリを起動します。
ノッチアプリ本体は別途必要です。すべてのアプリ・表示状態への互換性を保証するものではありません。
